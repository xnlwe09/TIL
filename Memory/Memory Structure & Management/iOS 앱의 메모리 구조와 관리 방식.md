# iOS 앱의 메모리 구조와 관리 방식

## iOS의 메모리 구조

- 힙(Heap) 영역
- 스택(Stack) 영역
- 코드(Code) 영역
- 데이터(Data) 영역

<aside>

## 1️⃣ 힙(Heap) 영역

### 특징

- 동적으로 할당된 메모리를 저장하는 곳
- 객체(Object), 클래스, 인스턴스, 동적으로 생성된 데이터 등이 힙 영역에 할당
- 메모리 크기는 고정되어 있지 않고, 필요에 따라 증가하거나 감소 가능
- 개발자가 명시적으로 메모리를 할당하고 해제해야 하며,
    
    주로 malloc, free 같은 함수나 Objective-C와 Swift에서 제공하는 메모리 관리 방법을 사용
    

### 관리 방식

- ARC(Automatic Reference Counting)로 메모리를 관리
</aside>

## 2️⃣ 스택(Stack) 영역

### 특징

- 함수 호출 시 할당되는 메모리 공간
- 함수의 매개변수, 반환 주소, 로컬 변수 등이 저장
- 메모리 할당 및 해제는 LIFO(Last In First Out) 방식으로 이루어짐

### 관리 방식

- 스택 메모리는 자동으로 할당 및 해제
- 함수가 호출되면 스택 프레임 생성 → 해당 함수의 로컬 변수가 저장되고, 함수가 종료되면 스택 프레임 파괴
    - 스택 프레임 : 함수가 호출되면 해당 함수의 스택 프레임이 스택에 쌓임 (함수의 매개변수, 로컬 변수, 반환 주소 등이 포함)
    - 로컬 변수 : 함수 내에서 선언된 로컬 변수는 해당 함수의 스택 프레임에 저장
        
        함수 호출 - 자동 할당, 함수 종료 - 자동 해제
        
</aside>

## 3️⃣ 코드(Code) 영역

### 특징

- 실행 파일의 코드(명령어)가 저장되는 영역
- 프로그램이 시작될 때 메모리에 로드 (읽기 전용)
- 프로그램의 실행 중에 수정 불가

### 관리 방식

- 운영체제에 의해 관리
- 실행 파일이 로드될 때 필요한 코드가 메모리에 적재됨
- 읽기 전용이기 때문에 코드 수정이 불가능하며, 보안과 안정성을 높임
</aside>

## 4️⃣ 데이터(Data) 영역

### 특징

- 전역 변수와 정적 변수 등이 저장되는 공간
- 프로그램이 시작될 때 할당, 프로그램 종료 시점까지 유지
- 초기화된 데이터 / 초기화되지 않은 데이터 영역으로 나뉨
    - 초기화된 데이터 : 초기값이 있는 전역 변수와 정적 변수 저장
    - 초기화되지 않은 데이터 : 초기값이 없는 전역 변수와 정적 변수 저장

### 관리 방식

- 프로그램 시작 → 데이터 영역에 전역 변수, 정적 변수 할당
- 프로그램이 종료될 때까지 해당 변수들은 메모리에 유지
- 프로그램 종료 시 해제
</aside>
